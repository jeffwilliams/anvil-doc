If you use the Windows installer to install Anvil, the installer will write registry entries that add context-menu items to Windows Explorer for editing a file in Acme, or opening Acme in a directory.

However, if you install using the binaries directly you can use this as a template to create the entries: [anvil.reg](../../downloads/anvil.reg). Before importing it, edit the file and modify the paths to the Anvil executable.
